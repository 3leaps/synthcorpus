# synthcorpus v0.1.4 Release Notes

**Release date:** 2026-09-18

## Summary

**Patched Go baseline and Decernor v0.1.7 consumer pin**

synthcorpus v0.1.4 moves to Go 1.26.6, updates the YAML dependency to v3.0.5,
and pins the Decernor consumer contract to published `v0.1.7`. The corpus,
schemas, expected fingerprint records, and generated-real boundary are
unchanged.

## Highlights

- **Decernor consumer pin is tagged `v0.1.7`.** Machine pin and docs name
  `min_version` `0.1.7`, `preferred_tag` `v0.1.7`, and peeled commit `70efa26`.
  Exact committed-synthetic fingerprint goldens remain byte-identical. Locate
  remains an absolute `DECERNOR_BIN` or `PATH` lookup.
- **Go 1.26.6.** The patched standard library clears the advisories applicable
  to the previous Go 1.26.4 baseline.
- **YAML v3.0.5.** The direct YAML dependency receives its patch update;
  `edwards25519` remains at v1.2.0.
- Repository and both generators report version `0.1.4`.

## Governing invariant

Generated-real material never enters the repository. Only registered,
provably unusable committed-synthetic specimens live under `fixtures/`.

## Decernor contract

The consumer pin is tagged Decernor `v0.1.7` (`70efa26`). Exact goldens are
unchanged from the prior pin. Generated-real checks validate properties only in
an isolated output root and retain no generated key material or fingerprints.

## Verification

- `GOTOOLCHAIN=go1.26.6 go run golang.org/x/vuln/cmd/govulncheck@v1.8.0 ./...`
  reports no symbol-, package-, or module-level vulnerabilities.
- `DECERNOR_BIN=/absolute/path/to/decernor make check-all` runs formatting,
  tests, build, scanner canaries, negative-crypto proofs, release controls, and
  both consumer-contract lanes.
- Dependency licenses pass the existing high-severity assessment.

## Compatibility

No migration is required. Consumer contract callers must supply a Decernor
binary satisfying `manifests/decernor-pin.json` (`v0.1.7` / `70efa26`).

## Release vehicle

v0.1.4 is a GPG-signed Git tag plus GitHub release notes. GitHub's automatic
source archives are expected. No prebuilt generator binary, package-manager
artifact, separately attached corpus bundle, artifact signature or key,
checksum manifest, or provenance asset is published. Generated-real material
is not part of the source tree or release.
