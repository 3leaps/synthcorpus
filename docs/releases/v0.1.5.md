# synthcorpus v0.1.5 Release Notes

**Release date:** 2026-09-24

## Summary

**Decernor v0.1.8 consumer pin and binary lookup order**

synthcorpus v0.1.5 pins the Decernor consumer contract to published `v0.1.8`
at peeled commit `08c0afc`. The corpus, schemas, and exact fingerprint goldens
are unchanged.

## Highlights

- The machine pin names `min_version` `0.1.8`, `preferred_tag` `v0.1.8`, and
  `preferred_commit` `08c0afc`.
- Binary lookup uses an explicit absolute path, then
  `THREELEAPS_SYNTHCORPUS_DECERNOR_BIN`, `DECERNOR_BIN`, and `PATH`. A non-empty
  explicit or environment choice that is unusable fails without falling back.
  The legacy `env` pin field and `DECERNOR_BIN` variable remain supported.
- The Go directive remains 1.26.6. `edwards25519` remains v1.2.0 and YAML
  remains v3.0.5; no patch module update was available.
- Repository and both generators report version `0.1.5`.

## Governing invariant

Generated-real material never enters the repository. Only registered,
provably unusable committed-synthetic specimens live under `fixtures/`.

## Decernor contract

The published Decernor v0.1.8 darwin arm64 binary reports version `0.1.8` and
commit `08c0afc`. Exact committed-synthetic goldens remain byte-identical, and
generated-real checks validate properties in an isolated transient output root.

## Verification

- `THREELEAPS_SYNTHCORPUS_DECERNOR_BIN=/absolute/path/to/decernor make check-all`
  covers formatting, unit tests, build, scanner canaries, negative-crypto
  proofs, release controls, and both consumer-contract lanes.
- `go list -m -u all` shows no available module update; `go mod tidy -diff`
  is clean.
- `GOTOOLCHAIN=go1.26.6 go run golang.org/x/vuln/cmd/govulncheck@v1.8.0 ./...`
  reports no vulnerabilities. The dependency license assessment passes at
  the high-severity threshold. These assessments run separately from
  `make check-all`.

## Compatibility

Consumer contract callers must supply a Decernor binary satisfying
`manifests/decernor-pin.json` (`v0.1.8` / `08c0afc`). Existing
`DECERNOR_BIN` use remains valid unless the repo-scoped variable is set.

## Release vehicle

v0.1.5 is a GPG-signed Git tag plus GitHub release notes. GitHub's automatic
source archives are expected. No prebuilt generator binary, package-manager
artifact, separately attached corpus bundle, artifact signature or key,
checksum manifest, or provenance asset is published. Generated-real material
is not part of the source tree or release.
