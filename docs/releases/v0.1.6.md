# synthcorpus v0.1.6 Release Notes

**Release date:** 2026-10-13

## Summary

**GnuPG agent key specimens and a Decernor verdict contract**

synthcorpus v0.1.6 adds committed-synthetic GnuPG agent key specimens, an
expected-verdict manifest for them, and a contract lane that checks a pinned
Decernor binary against that manifest. The Decernor consumer contract pins
published `v0.1.9` at peeled commit `43f57d9`.

## Highlights

- `fixtures-agent/` holds placeholder-only GnuPG agent key specimens, in
  extended and canonical forms: plaintext, passphrase-protected, smartcard and
  TPM shadow stubs, malformed and ambiguous forms that must fail closed,
  keyring-internal files, and benign look-alikes. Every key parameter is a
  placeholder, and provability checks confirm it.
- `manifests/decernor-scan-verdicts.json` (v0) gives each specimen's class,
  the placement a consumer stages it at, the expected `scan` finding per
  profile (`artifact` and `workstation`), and the expected `guardread`
  verdict. Classes declare invariant rules from a closed vocabulary.
  Expectations come from the GnuPG key format and each specimen's class
  intent, not from detector output.
- `make verdict-check`, part of `make contract`, stages every specimen at its
  placement, runs the pinned binary's `scan` in both profiles and `guardread`,
  and checks the exact expected findings, the guardread verdict, and every
  rule the specimen's class declares.
- The generated-real contract expects 23 records. Decernor v0.1.9 reports the
  two agent key files in the generated GnuPG home as `unsupported-kind` with
  no fingerprint; the contract fails if any record in that directory carries
  a fingerprint.
- The minimum Go version is 1.26.9. Repository and both generators report
  version `0.1.6`.

## Governing invariant

Generated-real material never enters the repository. Only registered,
provably unusable committed-synthetic specimens are committed.

## Decernor contract

Decernor v0.1.9 reports version `0.1.9` and commit `43f57d9`. Exact
committed-synthetic goldens remain byte-identical. The verdict lane and the
generated-real checks pass against it.

## Verification

- `THREELEAPS_SYNTHCORPUS_DECERNOR_BIN=/absolute/path/to/decernor make check-all`
  covers formatting, unit tests, build, scanner canaries, negative-crypto
  proofs, release controls, and all three consumer-contract lanes.
- `go list -m -u all` shows no available module update; `go mod tidy -diff`
  is clean.
- `GOTOOLCHAIN=go1.26.9 go run golang.org/x/vuln/cmd/govulncheck@v1.8.0 ./...`
  reports no vulnerabilities. This assessment runs separately from
  `make check-all`.

## Compatibility

Consumer contract callers must supply a Decernor binary satisfying
`manifests/decernor-pin.json` (`v0.1.9` / `43f57d9`). Building requires Go
1.26.9 or later.

## Release vehicle

v0.1.6 is a GPG-signed Git tag plus GitHub release notes. GitHub's automatic
source archives are expected. No prebuilt generator binary, package-manager
artifact, separately attached corpus bundle, artifact signature or key,
checksum manifest, or provenance asset is published. Generated-real material
is not part of the source tree or release.
